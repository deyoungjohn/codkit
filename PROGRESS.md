- **LI.FI provider** (`/lifi`, mainnets only; it declines testnets and local chains): keyless quote API. Because it returns calldata to sign, the response is rejected unless chain, tokens and amount echo the request, an ERC-20 input attaches no value, and a native input attaches exactly the amount. Docs will say to pair it with `allow.programs`.
- **Solana adapter** (`/solana`) and **Jupiter provider** (`/jupiter`, mainnet only): SOL and SPL balances and transfers (the recipient's token account is created if missing; Token-2022 mints are refused, not mishandled), transactions built at the moment of use so a long wait for approval can't expire the blockhash, confirmation by polling, a failed or unconfirmed transaction releases the reserved spend. Jupiter hands back a transaction to sign, so before signing the adapter checks that the fee payer is the agent and that every top-level program is on a short allowlist (checked against a real Jupiter transaction: ComputeBudget, ATA, System, Token and Jupiter v6 only), then simulates and compares balances: it may not take more than the swap's input plus a fee allowance, or return less than the guaranteed minimum.
- **Left out on purpose:** Jupiter's `priceImpactPct`. Its unit isn't established (0.1 SOL gave 0.0000065, 10,000 SOL gave 0.0023, which looks like a fraction), and a wrong unit is worse than no number.
